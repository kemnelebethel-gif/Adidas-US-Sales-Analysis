# Adidas US Sales Analysis Dashboard

## Project Overview
This project analyses Adidas sales performance across the United States using Power BI. The dashboard provides insights into sales, profit, products, retailers, regions, states and monthly trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Key Areas of Analysis
- Total sales and profit
- Product performance
- Retailer performance
- Regional and state sales
- Monthly sales trends
